# DoSJE Monitoring Platform — SIH 2026 Prototype

A demo-ready centralized monitoring and inspection prototype for projects/institutes/NGOs operating under DoSJE schemes.

## Prototype Modules
- Real-time monitoring dashboard
- Project monitoring and status
- Live CCTV demo interface
- Random Video Conferencing trigger
- AI-assisted attendance/anomaly analytics demo
- Random inspection assignment
- Mobile inspection workflow
- GPS/time-tagged evidence capture demo
- Digital inspection report and verification

## Demo Flow
Login → Dashboard → Project → CCTV → AI Alert → Random Inspection → Inspector App → Geo-tagged Evidence → Report

## Run locally
Open `index.html` in a browser.

## Deployment
This is a static prototype and can be deployed using GitHub Pages, Vercel, or Netlify.

> CCTV, VC, AI and GPS shown in this prototype are demo interfaces. Production deployment requires authorized integrations, secure authentication, privacy controls, and government-approved infrastructure/APIs.
